# 150 — Memex

`.knowledges/` holds durable notes on how this repo works, one entry per mechanic.

- **Before** reading package source to work out how something behaves, read `.knowledges/<package>/index.md` and the entries it links.
- **Trust** `status: stable` entries as written. Treat `status: draft` — or a "where to look" symbol grep cannot find — as a hint to confirm against source.
- **After** deriving a mechanic no entry covered, run the memex skill's `capture` before you finish; after changing a mechanic an entry documents, run a sync for that package.

Entries record mechanics *below* the public contract; see `.knowledges/CONVENTIONS.md` for what earns one.
